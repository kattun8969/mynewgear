## 1. 今回の優先順位
- **P0：写真付きの具体的な購入候補、正しい型番、購入先、画像権利と正規ASPカードを準備**。リンクが用意できないからと文章だけで仮完成にしない。
- **P0：短い文章・適度な改行・最初に見せる商品・導線の整理**。難しい前置きではなく「欲しい音→商品→理由→比較」を優先。
- **P1：古い稿の機材を落とさない**。説明不要なものは「周辺機材」「別公演」の短い枠で扱う。
- **P2：本人動画の全機材タイムコード照合**。ただし本人使用を断定する個別機材はその断定を裏付ける情報が必要。不明は「確認できた資料では不明」。

## 2. 冒頭の配置順（PC・モバイル共通）
1. リード文（購入前の悩み、この記事で選べることを簡潔に）。広告・PR表記。
2. 本人演奏／ボード紹介の動画（正規埋め込み、16:9）。動画2本を大量の文章で分断しない。
3. 「最初に見る5機材」写真付きカード：G2 FOUR / BD-2 / MS-70CDR+ / VIRTUES monica / Myriad Fuzz。**すべての型番・販売ページ・画像権利が明確になるまで公開用としては未完成**。
4. 「本人が過去に紹介した機材」一覧。原稿の過去時点ラベルを付ける。
5. カテゴリー別紹介：各H2内で「過去使用」→「低価格」→「編集部おすすめ」。同一用途でも音の差を短文で示す。
6. 予算別、人気曲と音作り、別公演・周辺機材、FAQ、まとめ。

## 3. 共通商品カードのコンテンツ（商品ごと）
- 画像（正式ASP提供または許諾済み）／製品名／モデル名・世代／音の特徴1行／向いている人1行
- 他製品との差・弱点1行。商品の具体的な弱点を記し、全商品共通の「在庫注意」を弱点として繰り返さない。
- 現行価格の記載は確認日・販売者・新品中古が特定できる場合のみ。なければ価格を断言しない。
- 購入ボタンは **実際に有効な正式ASPリンク** のみ。メーカーURL・通常通販URLを成果計測可能なアフィリエイトURLと誤認しない。
- Public GitHubは商品IDや公式出典、配置指定まで。認証値、管理画面HTML、ユーザー固有のトークンを掲載禁止。

## 4. ①ライターへの追加提出条件
`products.csv`の最優先5件、続いて記事内のメイン比較商品について以下の空欄を埋める：
- 固有の販売候補URL（カテゴリ一覧URLでなく、対象製品ページ）
- 本文と一致する型番・世代
- 商品画像の表示方法（ASP商品カード内画像／公式埋め込み／許諾済み素材）
- 購入候補としての採用理由／比較対象との違い
- 試奏動画URLがある場合は製品に結びつけ、本人演奏動画と製品デモを区別
国内価格は可能な範囲で確認日・販売者をつける。架空価格・架空ASPリンク・画像転載は禁止。

## 5. ②Workへの引き継ぎ後の検証
