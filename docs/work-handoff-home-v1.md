## 実装時の手順（承認後のみ）
1. DB+ファイルの完全バックアップを取得。既存TOP、カスタマイザー設定、メニュー、子テーマCSS、広告設定を記録する。
2. WordPressの**非公開固定ページ**を作成し、SANGO側の不要な記事見出し・余白を必要最小限に調整。公開トップは維持。
3. HTMLをカスタムHTMLブロックに貼り、CSSは子テーマ管理CSSに保管。コアテーマファイルを変更しない。
4. 既存プラグインを確認。Pochippが有効か、Rinker記事に表示崩れがないか、キャッシュ最適化・SEOタグ重複がないか検証。
5. 商品カードの「正規画像の配置予定」枠は**実際の許諾済み画像／Pochippカードに置換後のみ完成**。メーカー・販売店の写真を無断でコピーしない。現在のリンクは比較記事への誘導であってアフィリエイトリンクではない。
6. PC（約1280px）とスマホ（375px・320px）で横スクロール、見出し、画像、CTA、メニュー表示を確認する。アートディレクション画像案の見た目を機械的に再現する義務はない。
7. 検証URL、画面キャプチャ、問題点、修正したGitHubコミットを⓪に提出。**TOPへの設定変更は⓪の明示承認後**。

## 公開前に解決が必要
- サイトロゴ（横長）とファビコン（512pxマスター）の正式デザイン・媒体権利。以前のイメージ生成案は未採用の参考であり、実際の商品写真とは扱わない。
- 記事カード、画像、商品カードに使う本番メディアと正式なリンク先の選定。
- ナビゲーションのリンク切れ検証。予算・音のリンクは現在検索URLへの暫定導線。
- Site Kit / GA4とAd Inserterの計測イベント設計。AdSense独自クリック検出禁止。
- ページをトップにしたときの標準SEOメタと検索エンジン公開可否の再確認。非公開試作を本番公開しない。

## 安全
GitHub Publicに認証情報、管理画面HTML、WordPress nonce、ASP管理画面からの非公開情報は保存禁止。公開記事・既存Rinker・Pochipp・カエレバ広告は変更しない。
