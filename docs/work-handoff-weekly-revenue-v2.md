# ②Work即時実装指示｜TOPの「今週の注目機材」収益優先版（2026-11-25）

### フォールバック実装済み（2026-11-25追記）

**プラグイン側に旧TOPカードを表示する安全なフォールバックを追加**（commit `9018e2ca`）。WordPressで以下を実施するまで本番差し替え不可。

1. 現TOPの3商品紹介部分（BD-2／monica／Myriad Fuzz）をWordPressの**同期パターン（`wp_block`）**として複製保存。同期パターンIDを取得。元の3枠はバックアップしたままにする。
2. 非公開テスト用ページで、`[mng_weekly_gear count="3" fallback_block="取得した同期パターンID"]`を入力。
3. 6件満たない場合、保存済み旧3商品カードがショートコードの位置に表示されることを検証。
4. 6件すべての在庫・成果リンク・記事条件を満たす場合は、横スクロール2段×3件に置き換わることを検証。
5. **在庫確認日を8日以上前にずらすテスト**で、自動的に旧3商品カードが再表示されることを確認。期限切れの週に購入導線が消えてはいけない。
6. リンクの重複・ショートコード再帰・表示崩れ・キャッシュを検証し、旧TOPブロックを直ちに復元できる体制で切り替える。
7. **`fallback_block` 未設定のまま本番へは公開しない**。登録済みの商品データが0件なら表示が空になるため。

このフォールバックは投稿内容に保存されたブロックを表示する機能であり、**本物の商品の在庫があるかを自動検査する機能ではない**。ショップ別在庫は人間が確認して管理画面に登録する。


## 2026-11-25 公開審査：本番切替をまだ行わない（修正実装は進行可）
