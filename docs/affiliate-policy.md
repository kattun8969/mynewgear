# アフィリエイト・広告運用方針

- PR表記を記事冒頭など適切な位置に明示する。
- 記事の目的は「購入前に安心して選べること」。購入を過度に煽ったり、機能を誇張しない。
- 商品カードは商品説明と同じ場所に配置し、比較と購入検討を妨げない。
- もしも/カエレバ/Rinker等は実際の管理画面で生成されたコードを使用。リンク文字列を推測生成しない。
- PublicリポジトリにASPの広告ID、成果計測識別子、ASPログイン情報を登録しない。公開してよい資料のみに限定。
- 広告リンクの有効性は①リンク先の適合②提携状態③成果計測の3つを分けて評価。
- リンクの実装・改修はWordPress側で実施し、結果のみIssueやレビューに記録する。
