# まいにゅーぎあー｜サイト全体リニューアル設計 v1

状態：**⓪総合管理の提案／未承認／WordPress未反映**  
対象：https://mynewgear.cyou/　制作日：2026-11-24

## 1. 目標と現状
現在の公開トップは、古いブログ形式の投稿日付き一覧と汎用カテゴリナビ中心。2020–2021年公開の記事が上部に並び、ユーザーが「好きなアーティストの音を再現する機材」「買える代替商品」を直感的に探しにくい。

**サイトの約束**：「あのギターの音に近づくために、何を買えばいいか分かる。」

対象：コピーしたい曲・好きなギタリストは分かるが、必要な機材を持たず、購入判断に迷っている人。既存機材を使えるケースは買い足しの必要性も説明する。

**主要CV**：記事→商品カード→ショップの有効なアフィリエイトリンクのクリック、最終的なASP成果。**補助**：アーティスト記事回遊、記事内の比較閲覧、検索流入。成約はGA4ではなくASP管理画面で確認。

## 2. デザインシステム（暫定）
- 印象：ギター機材専門誌 × 楽器セレクトショップ。情報と写真が主役、装飾過多にしない。
- ベース：白 `#FFFFFF`／薄いグレー `#F5F7F8`、主文字 `#17212B`、補助 `#52606D`。
- ブランド色：深いネイビー `#132438`、アクセント・購入導線 `#D86A32`、リンク `#17689B`。これは**試案**。正式ロゴを採用するまで配色は確定しない。
- フォント：まずシステム日本語フォント。外部Webフォントの増設はしない。
- 最大幅：サイト全体 `1180px`、本文 `760px` 目安。文字本文 PC `16–18px`、スマホ `16px` を下限目安。行間1.75～1.9。
- タップ領域：44px以上を目安。キーボードフォーカス表示。色のみで「本人使用／推定」を区別しない。
- 画像：実機・本人公式投稿・許諾済み製品写真・Pochippの正式商品カード画像のみ。AIで実在機材の画像を創作しない。
- 商品カード：PCは最大2列／スマホ1列。写真、製品名、用途、他候補との違い、ボタン。価格は日付・店舗・新品中古の根拠がある場合のみ。
- 記事内：太い見出し + 必要最小限の「POINT」「注意」枠。旧Cocoon吹き出しの乱用を廃止。元記事から説明を削るのではなく情報を読みやすく再配置する。
- PR表示はユーザーが商品紹介へ到達するより前に明瞭に置く。

## 3. トップページの情報構造
1. **ヘッダー**：「まいにゅーぎあー / MY NEW GEAR」、検索、アーティスト別／音から選ぶ／予算別／機材レビュー。スマホではシンプルなメニューと検索。
2. **ファーストビュー**：1行の価値提案 + 短い補足 + 「アーティストから探す」「欲しい音から探す」の選択。巨大な抽象ギター画像は不要。
3. **注目記事（編集部選定）**：当初はYOASOBI/AssH、King Gnu、ヨルシカ。**未更新の古い記事には「最新」バッジ禁止**。リライト完成後のみ新デザインの推奨面に採用。
4. **アーティストから探す**：既存記事への実リンク。人物写真の使用許諾不明なら文字＋実在機材画像で表現。
5. **欲しい音から探す**：軽い歪み／迫力のある歪み／ファズ／響き・空間系／ワウ・オクターブ。**音色カテゴリは検索導線の設計案**。未整備なら空ページを公開せず検索や既存の関連ページへ導く。
6. **予算から探す**：1万円前後／3万円前後／5万円前後／本人と同じ機材。予算は記事・製品実売の根拠に基づき、金額別記事が整うまでは説明リンクとして扱う。
7. **機材のレビュー・比較**：本人使用と別にブランドや用途で探せる。
8. **新着・更新記事**：更新日を機械的に付け替えない。内容更新したものだけ「更新」。
9. **フッター**：運営者、広告・PRポリシー、プライバシー、お問い合わせ、サイトマップ。

## 4. 記事共通の見せ方
リード（検索意図と購入前の悩み）→本人の動画または音の参考（利用条件を確認）→機材の写真付き一覧と用途→カテゴリーごとの本人機材・低価格・独自おすすめの比較→購入パターン／予算→曲の音作り→FAQとまとめ。

**順番は固定テンプレではない**。曲の再現が目的なら、曲と必要な音を最初に示してもよい。

- 商品名の羅列は禁物。各商品に「この音が欲しい人」「どう他候補と違うか」を1–2文で書く。
- 歪みが記事の中心とは限らない。ワウ、オクターバー、ディレイ等の重要度はアーティスト・曲による。
- 「本人使用」は誰が・いつ・どのボードか明記。確認できないときは不明とし、推定商品を本人機材と誤認させない。
- 画像・動画不足を文章で埋め合わせて完成扱いしない。
- 動画の埋め込みは正規のYouTube等の方法で行う。画像ファイルの転載とは扱いが異なる。

## 5. ロゴ・ファビコン仕様（制作依頼）
- ロゴ文字：「まいにゅーぎあー」、補助文字「MY NEW GEAR」。
- 小さくしても識別できる**シンプルな機材／ピック／波形の抽象記号**。既存ブランドロゴやメーカーの商標をトレースしない。
- 横長ロゴ（ヘッダー用）、正方形ファビコン（512pxマスター）を同一デザインから派生。
- 配色は主にネイビー＋暖色アクセントの2色。単色表示、明暗背景、32px角で潰れないか検証。
- ラスタ画像と可能ならSVGの原稿を用意。WPメディアへは最終的な推奨形式に変換し登録。
- **現時点で画像を生成・採用したわけではない**。実物のロゴ・ファビコンは別途制作・承認が必要。

## 6. SANGO実装と既存資産保護
- SANGO子テーマを継続。トップは固定ページ案を第一候補とし、WordPress設定のフロントページ切替は検証後に実施。
- デザイン共通CSSは子テーマ側に**限定的なクラス接頭辞 `mng-`**で実装。テーマ本体ファイルに直接変更しない。
- テンプレ試作品は `templates/site-home-prototype.html`。**公開設定、GitHub Pages、自動デプロイの対象外**。
- 既存公開記事のURL、アイキャッチ、メタ、広告リンク、内部リンクをバックアップし、複製下書きで作業する。
- 旧Cocoon装飾は段階的に置換。元情報を維持し、差分台帳を保存。
- 商品カードの新規標準はPochipp。既存Rinker／カエレバ／もしもカードは置換完了まで維持。サウンドハウスの正式アフィリエイトURLはアクセストレード側の発行・規約・提携を確認後に追加。店名ボタンだけ先に置かない。
- ACFは必要な構造化項目が確定してから使用。アーティスト・機材タグはWordPress分類法（カテゴリ／タグ／タクソノミー）との重複を回避。
- Ad Inserterは共通広告枠。Pochippの商品カードとは別。広告の過剰挿入をしない。GA4のクリック計測とASP成果は区別。
- WP Fastest Cacheなどキャッシュをクリアするのは、保存後の表示確認手順に沿って。

## 7. プラグインの前提（オーナー2026-11-24画像）
導入済み：Ad Inserter、Advanced Custom Fields、Pochipp、Redirection、Rinker、UpdraftPlusほか。**画像時点ではPochippは無効**。実装担当は有効化と動作確認が必要。Rinkerは削除禁止。

UpdraftPlusでDB＋ファイルのバックアップを取得し、外部保管と復元手順を確かめてからテンプレや共通CSSを変更する。旧プラグイン依存ブロックの残存を棚卸しする。

## 8. 計測方針（設計段階）
- GA4: クリック可能な**自サイト管理リンク**のみ `affiliate_click` を計測。`site_id`, `article_id`, `placement`, `merchant`, `product_id` 等。プラグインの既存計測と二重発火しないこと。
- `ad_slot_view` は自社制作広告枠のビューポート露出を条件付きで測る（単にDOMにあるだけは表示としない）。
- AdSenseなど第三者の広告クリックを独自JavaScriptで収集しない。
- クリック数は購入成立数ではない。ASP成果・承認額と別にダッシュボード化。
- 計測タグはプライバシー／同意管理方針に整合させる。
