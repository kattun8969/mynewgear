# 編集方針

## 読者
好きなアーティストの音に近づくため、必要な機材を**これから買いたい**ギタリスト。購入前の迷いと失敗への不安を解消する。

## 記事構成の原則
1. 共感できるリード文。この記事で選べるようになるものを明示する。
2. 実際の演奏や本人の機材紹介動画を早めに配置する。
3. 本人使用機材を写真・名称・役割・確認時期つきで俯瞰する。
4. 同じ用途の本人機材／低価格候補／編集部推奨を近くで比較。別見出しに機械的に分断しない。
5. 購入優先順位、予算別構成、マルチ機材も必要に応じて提案する。
6. 人気曲の音作りで機材を買う根拠を補強する。曲の選定はトレンドと検索意図次第。

見出し順は読者ニーズに応じて変更可能。歪み系偏重にしない。

## 根拠
本人使用機材は人、時期、曲、用途を区別する。本人確認と編集部推定を混同しない。音の方向性が異なる機材を同等品と断定しない。試奏していなければ試奏したと書かない。

## 書き方
短文・適切な改行・平易な説明。音作りは「低域を控えめに」「中域を増す」など方向性を中心とし、根拠のないノブ位置画像・AI生成の架空機材は使わない。

## ビジュアル
主要機材はできるだけ正しい商品写真で示し、公式SNSやYouTubeの正規埋め込みを活用する。権利と規約に注意する。量だけでなく閲覧体験を評価する。
