# まいにゅーぎあー｜ブランドロゴ・ファビコン v1（試作）
状態：**⓪管理用試作／採用・WordPress反映は未承認**

## 仕様
- シンボル：一般的なギターエフェクターを抽象化した線画。メーカー製品の筐体・ロゴを模倣しない。
- ロゴ：『まいにゅーぎあー』を主役、英字『MY NEW GEAR』を補助。背景は白を想定。
- 色：ネイビー `#0B1A34`、オレンジ `#FF8A00`、白 `#FFFFFF`。
- 必要な納品：透過背景の横長ロゴPNG、ファビコン512px/192px/32px PNG、編集可能なSVG原稿。
- 現在のSVGの文字部分はフォント参照型。**環境で文字幅・外観が変わる可能性あり**。最終版では表示環境を検証し、必要なら文字をアウトライン化する。
- WordPressはSVGアップロードが標準で制限されるため、媒体にはまずPNGを使用する。

## WordPressへの適用（②Work担当、承認後）
1. ヘッダーロゴを先に**非公開プレビュー**でテスト。スマホでブランド名が読めるか確認。
2. WordPressのサイトアイコンへ512px PNGを設定し、32px表示で視認性・形状を確認。
3. 既存ロゴ、ファビコン、テーマ設定、キャッシュを変更前に保全する。
4. PC/スマホ・ブラウザタブ・OGPを分けて確認。ファビコンはOGP画像の代用品にしない。
5. PR #2のトップHTML/CSSと合わせてデザイン承認を取るまでは本番反映しない。

## ファイル
- `assets/brand/brand-icon.svg` — 正方形マークの編集可能なベクター原稿
- `assets/brand/brand-logo-horizontal.svg` — 横長ロゴの編集可能なベクター原稿
- PNGは会話添付のブランド素材ZIPで引き渡し（公開リポジトリにはSVGのソースを保管）。
