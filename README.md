# まいにゅーぎあー｜記事制作リポジトリ

公開サイト: https://mynewgear.cyou/

このリポジトリは記事・商品選定・出典・レビュー履歴の管理用です。WordPressの本番サイトをデプロイするためのものではありません。

## 運用（3チャット）
1. **①ライター**：調査、記事・素材・商品台帳作成。変更はPull Requestで提出。
2. **⓪総合管理**：読者目線、正確性、SEO、アフィリエイト導線、媒体ポリシーを審査し承認。
3. **②Work**：承認版のみをWordPressの下書きに反映し、PC/スマホ、リンク、埋め込みを確認。既存公開記事は勝手に変更しない。

## 最初の対象
YOASOBI／AssH の完成見本を優先。旧稿は資料として参照し、素材・広告コードを無条件に複製しない。

## 公開リポジトリの安全ルール
- パスワード、APIキー、トークン、Cookie、ログイン済みHTML、WordPress nonce、個人情報は絶対にコミットしない。
- ASP管理画面からコピーした識別子つきリンク・広告コードは原則この公開リポジトリに保存しない。WordPress内で管理し、ここでは `WP管理対象` と記載する。
- 正式なASPコードの発行・提携有効性・成果計測は認証済み管理画面で個別に検証する。
- 他サイト画像のコピーは保存しない。画像・動画は掲載許諾または正規埋め込みを確認する。
- 本リポジトリからWordPressへの自動公開は行わない。Actionsは設けない。

## ディレクトリ
- `articles/<slug>/article.md`: 記事原稿
- `articles/<slug>/products.csv`: 商品・比較候補台帳（ASP IDなし）
- `articles/<slug>/sources.md`: 根拠・写真・埋め込み候補
- `articles/<slug>/review.md`: 総合管理・Workの確認事項
- `docs/`: 編集・広告・品質基準
- `templates/`: 横展開のテンプレート
